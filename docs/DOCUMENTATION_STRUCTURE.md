# Documentation structure and migration

**Executive summary:** begin with a short explanation, select the question you
need, then open the detailed analysis. Research and historical background now
share one section. Original constitutional and experimental evidence stays
separate from current guidance.

## Reading levels

| Level | Reader need | Location |
|---|---|---|
| 1: orientation | What is this, who is it for, what is its status? | Root README and getting-started guide |
| 2: practical route | Which context, review depth or institutional form fits? | Applications, process and modular profiles |
| 3: explanatory evidence | Why these ideas, what conflicts and limits remain? | Research findings, history, films and academic studies |
| 4: reconstruction/verification | Exact decisions, requirements, sources and observations | Constitutional records and testing archives |

Summaries should use plain language and state material limits upfront. Deeper
analysis remains available through descriptive links. Use tables for choices,
short paths for common tasks and expandable lists for optional references.
Critical status and evidence limitations must not be hidden inside a disclosure.

Six small relocation notices preserve old public paths and pointers in frozen
material. They are compatibility aids, not duplicate maintained analyses.
Current navigational links use the canonical destinations. Earlier versions
remain in Git history. External links to old section fragments may need to open
the maintained destination explicitly; a Markdown notice is not an HTTP redirect.

## What remains stable

Constitution v0.1, original decisions/requirements, source-status registers,
harness code, fixture inputs and frozen result archives have not been rewritten.
Academic essays retain their detailed bodies and gain plain-language summaries.
Testing remains in its own section; film-inspired research is not experimental
evidence. Runtime engineering remains explicitly deferred.

## Public distribution boundaries

The short entry point is suitable for public research distribution. It is not
proof of adoption, efficacy, legal completeness or IP clearance. The owner still
has moved the repository to
[cogno-us/constitutional-governance-for-institutions](https://github.com/cogno-us/constitutional-governance-for-institutions).
An exact release snapshot and optional archival deposit remain owner decisions. A private reporting route, continuity and independent review
must be verified rather than invented. See [release guidance](RELEASE_GUIDANCE.md)
and [remaining work](REMEDIATION_STATUS.md).

Documentation usability still needs actual newcomer review. This refactor checks
links and conformance, not comprehension. Future contributors should improve the
shortest path before adding new parallel indexes or repetitive sections.
