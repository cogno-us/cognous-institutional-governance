# Provision-to-implementation mapping

**Summary:** Each row identifies what an institution must supply and what a
consumer must implement. Documentation and local reference checks are not
operational enforcement. Read [scope and pinned source revisions](README.md).

**Status vocabulary:** N = normative design requirement, conditional on actual
controlling authority; P = documented human procedure; R = locally implemented
reference checks; T = executed local fixture behavior; E = operational enforcement.
This publication has **no E claims**. N does not mean adopted law. The Constitution
references below refer to the unchanged v0.1 proposal at the baseline commit;
C references are the unadopted Core Charter revision at that same commit.

This is the relevant public-stack interface mapping, not certification of every
constitutional procedure. Membership, elections, judicial selection, emergency
proof standards and full adoption cannot be inferred from this machine profile.
