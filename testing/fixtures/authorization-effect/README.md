# Authorization-to-effect fixtures

Twenty invented fixtures: two variants for each AE01–AE10 proposal. No production
data, confidential evidence, actual grants or news incidents are included.

Use the [battery](../../battery/AUTHORIZATION_EFFECT.md),
[harness design](../../harness/AUTHORIZATION_EFFECT_DESIGN.md) and
[execution archive](../../results/2026-10-05-authorization-effect-v1/README.md).
Inputs and expected observations are deliberately separate. Expected fields are
read by the oracle after effects, never passed into the policy or execution function.
All source validity, conflict, observer and verification flags are authored facts.
