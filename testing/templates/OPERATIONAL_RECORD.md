# Operational execution record template

- Record ID / case ID / configuration / version:
- Status: PROPOSED (change only with evidence).
- UTC date, repository commit, dirty state, fixture and adapter hashes:
- Actual responsible humans, grant source, purpose, scope and expiry:
- Affected people, relevant approvals, specialist requirements:
- Existing baseline; A/B/C differences, equal resources, allocation/confounders:
- Inputs, perturbation, predefined acceptance boundary and exclusions:
- Evidence source, independence dependencies and staffed alternative:
- Attempted actions and independently observed completed effects:
- Expected versus actual outcome; legitimate service retained; uncertainty:
- Contrary evidence, objections, dissent and unresolved state:
- Delays, cost, workload, interruption harm and adverse results:
- Reviewer's identity, qualifications, conflicts, reasons and disputed findings:
- Correction, receipt, remedy completion and remaining obligations:
- Human continuation decision: continue / narrow / withdraw / defer:
- Expiry, next review and follow-up actions:

Leave unknown fields UNKNOWN. Do not fill observations, authority or human review with generated assumptions. Link raw evidence and the actual execution record. This template supplies no authorization.
