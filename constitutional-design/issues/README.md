# Constitutional issues

Each descriptively named `IR-*.yaml` file is one initial constitutional issue
record. Its data uses JavaScript Object Notation, which is also valid YAML
Ain't Markup Language.

The initial records are inherited research questions, not inherited
constitutional answers. Every record remains `OPEN`; empty lists and explicit
`NOT_YET_INGESTED` values preserve missing evidence rather than imply
completeness.

`historical_evidence` contains identifiers that resolve to the shared
historical evidence register. A link records relevance only; it does not resolve
the issue or duplicate the analysis into the issue record.
