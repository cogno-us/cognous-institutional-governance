# Constitutional requirement template

```yaml
requirement_id:
statement:
status: CANDIDATE
source_issues: []
source_decisions: []
rationale:
constitutional_level:
implementation_boundary:
conflicts: []
dissent: []
verification_method:
draft_mapping: []
provenance:
```

Allowed statuses: `CANDIDATE`, `ACCEPTED_FOR_DRAFTING`, `DISPUTED`,
`REJECTED`, `SUPERSEDED`.

Do not accept a requirement for drafting without the required decision
provenance.
